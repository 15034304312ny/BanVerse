# 伴界 BanVerse v1.6.0

v1.6.0 集中完成角色扮演优化路线的阶段五至十，重点是让角色更连续、更可控，并让文本、图片和语音共享同一事件顺序。

## 新增与改进

- 本地脱敏诊断、角色质量基线和供应商/模型能力矩阵。
- 主角色模型与摘要、记忆、图片判断等辅助任务模型可独立选择。
- 可选的 Director → Actor 关键轮次规划，失败时自动降级为单次角色回复。
- 可查看、纠正、固定、删除的角色记忆，支持保留期限与每角色开关。
- 全局与每角色的关系节奏、称呼、话题边界、主动消息频率、静默、暂停和原因说明。
- 统一的文本/图片/TTS 分段事件源，图片生成失败不再影响已成功的文本。
- 角色卡新增稳定视觉身份、默认服装和负面约束；图片提示结合本地时段、已知场景和最近事件。
- 识图结果包含置信度与不确定项，低置信度 OCR、人脸身份和敏感属性不作肯定陈述。
- 自主发图增加每日预算、会话冷却、提示词去重、用户边界和幂等重试。
- TTS 按对白气泡顺序排队，排除旁白、动作、图片指令及合成控制标记。

## 兼容与安全

- 旧 SQLite 数据库、Character Card V2、同步账号和已保存的 API 配置可直接升级。
- 诊断包默认排除 API Key、Token、聊天正文、图片、音频和隐藏规划。
- Windows 便携版、安装器和卸载器继续使用项目固定的 Authenticode 自签名身份；该证书不受 Windows 公共 CA 默认信任。
- Android APK 继续使用从 v1.2.1 起的固定 release key，可覆盖安装同签名旧版。

## 校验

发布前执行完整 pytest、Ruff、版本一致性、Windows 启动冒烟、Authenticode 验证、Android APK 签名指纹与 16 KB ELF 对齐检查。
