# 伴界 BanVerse v1.6.1

v1.6.1 是一次双端界面体验更新，在不改变对话、同步、图片生成和 TTS
业务逻辑的前提下，统一桌面端与 Android 端的视觉语言和交互状态。

## 新增与改进

- 建立浅色与深色主题共用的语义设计令牌，采用暖白、翡翠绿和深墨绿色调。
- 统一按钮、输入框、下拉框、标签页、设置卡片、菜单、提示框和滚动条样式。
- 重做导航栏、会话列表和角色列表的悬停、选中、禁用与键盘焦点状态。
- 桌面聊天标题栏显示当前角色头像、角色名称和会话副标题，模型选择器不再挤压标题。
- 为用户消息、角色对白、旁白、输入提示和错误消息提供独立气泡层级。
- 优化图片附件预览、消息输入框、发送按钮和辅助操作按钮。
- 保持 Android 端不低于 44 px 的触控区域，并继续适配窄屏聊天布局。
- 调整深色主题的文字强调色，提高深绿背景上的可读性。

## 兼容与安全

- 兼容现有 SQLite 数据库、角色卡、同步账号、API 配置和媒体文件。
- Windows 继续使用项目固定的 Authenticode 自签名身份。
- Android 继续使用从 v1.2.1 起固定的 release key，可覆盖安装同签名旧版。
- 本版本不更改同步协议和服务器数据格式，v1.6.0 同步服务器可继续使用。

## 校验

发布前执行完整 pytest、Ruff、版本一致性、Windows 启动冒烟、
Authenticode 验证、Android APK 签名指纹及 16 KB ELF 对齐检查。
