# BanVerse 本地诊断与脱敏导出

BanVerse 默认在应用私有数据目录的 `diagnostics/events.jsonl` 记录有限的运行事件，
用于区分文本生成、回复解析、消息落库、后台摘要、角色状态、自主发图、TTS 与同步分别
在哪个阶段成功、取消或失败。事件文件自动轮换，最多保留当前文件和两个历史文件。

## 记录内容

- 应用版本、运行平台、随机会话 ID 与随机任务 ID。
- 功能类型、阶段、结果、脱敏错误码。
- 当前供应商和模型标识。
- 阶段耗时、调用次数、分段数、同步上传/接收/冲突数等有限数值。
- 后台摘要使用当前会话期内的一次性哈希引用关联来源轮次，不保存原始轮次 ID。

诊断摘要按功能阶段计算样本数、`p50` 和 `p95` 耗时。它们是本机体验基线，不是服务商
计费数据，也不会替代真实的 Token 用量。

## 不记录内容

- API Key、Token、密码、Cookie、Authorization header。
- 用户消息、AI 回复、提示词、思维链、角色卡、世界书和用户资料。
- 原始会话、轮次、账户和设备 ID。
- 图片、音频、数据库、TTS 缓存和启动日志。
- 文件绝对路径和电子邮箱。

诊断不会自动上传，也不会参与双端同步。第三方平台仍会按其接口处理正常聊天或媒体请求，
这与本地诊断记录是两条独立链路。

## 查看和导出

进入“设置 → 本地诊断”可以刷新或复制摘要。点击“导出脱敏诊断包”后，应用会先展示
包含项和排除项；确认后才允许选择保存位置。ZIP 中固定只有：

- `manifest.json`：格式版本、隐私清单和聚合摘要；
- `events.jsonl`：脱敏阶段事件；
- `README.txt`：给接收者的隐私说明。

导出包不会复制 `startup.log`、`chat.db` 或媒体目录。提交 GitHub Issue 前仍建议打开
`manifest.json` 复核包含项，并只分享与问题相关的诊断包。

## 开发验证

```powershell
.\.venv\Scripts\python.exe -m pytest tests/test_diagnostics.py --no-cov -q
.\.venv\Scripts\python.exe tools\generate_roleplay_baseline.py
```

诊断测试会检查常见 Key、Bearer Token、JWT、邮箱、私有路径和任意未在白名单中的详情字段
无法进入事件或导出包。默认 CI 和离线角色基线均不访问网络。
