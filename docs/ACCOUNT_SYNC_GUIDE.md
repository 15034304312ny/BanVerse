# BanVerse 账号登录与双端同步操作指南

本指南适用于 Windows 桌面端和 Android 手机端。最简单的使用方式是：在聊天数据
较完整的设备上注册账号并完成第一次同步，再在另一台设备登录同一账号。

## 数据流与账号的作用

```plantuml

}

```

账号用于让服务器判断两台设备是否属于同一个同步空间。每台设备登录成功后获得
独立的随机会话令牌；密码只用于登录，不会保存在 BanVerse 设置或聊天数据库中。
Windows 优先把会话令牌写入系统凭据管理器，Android 写入应用私有设置目录。

同步采用本地优先方式：两端各自保存完整 SQLite 数据，断网仍可聊天；联网后再交换
增量。服务器不是实时聊天模型，也不会保存文本、图片或 TTS 平台的 API Key。

## 推荐操作：先在 PC 注册，再在手机登录

### 第一步：PC 注册并上传已有数据

1. 打开 BanVerse，进入“设置 → 双端消息同步”。
2. “服务地址”保持默认 `https://47.102.121.29`。该选项位于“高级与兼容选项”中，
   普通用户不用修改。
3. 填写用户名。长度为 3–32 个字符，可使用中文、英文字母、数字、点、下划线和
   短横线；英文字母登录时不区分大小写。
4. 输入至少 8 个字符的密码，并在“确认密码”中再输入一次。
5. 如果服务器启用了邀请注册，填写管理员提供的“注册邀请码”。邀请码只用于注册，
   不是密码，注册后无需保存。
6. 点击“注册并登录”。看到“注册并登录成功”后，等待自动同步，或点击“立即同步”。
7. 确认状态显示“同步完成”，并记录“上传”数量。首次同步可能需要上传角色头像和
   聊天图片，耗时取决于图片数量和网络。

### 第二步：Android 登录并拉取数据

1. 打开手机端 BanVerse，进入“设置 → 双端消息同步”。
2. 输入 PC 端注册时使用的同一用户名和密码。手机端不需要再次填写邀请码。
3. 在“高级与兼容选项”中把设备名称改为易辨认的名称，例如“iQOO Neo8”。
4. 点击“登录”，随后点击一次“立即同步”。
5. 等待状态显示“同步完成”，返回“角色”和“消息”页面检查角色、会话、头像与聊天
   图片是否出现。
6. 在手机发送一条测试消息，等待回复完成；约 1.2 秒后 PC 会触发增量同步，后台另有
   15 秒兜底轮询。也可以在 PC 点击“立即同步”马上检查。

完成后，两端都可以独立聊天。不要在同一秒内修改同一个会话标题或同一张角色卡，
否则后提交的一端会记录为并发冲突；服务端先接受的版本作为当前版本。

## 如果已经使用 v1.3.0 的账户 ID 和令牌

旧版账户无需放弃，也无需重新上传云端数据：

1. 在目前仍能正常同步的设备打开同步设置。
2. 展开“高级与兼容选项”，确认账户 ID 和已保存的令牌仍然有效。
3. 在上方填写新的用户名、密码和确认密码。
4. 点击“升级旧版账户”。升级成功后，原账户 ID、云端消息、角色和图片都保持不变。
5. 为了防止旧令牌长期有效，升级会停用旧版主令牌。其他设备若提示登录失效，只需用
   新用户名和密码重新登录，不要重新注册。

“复制设备配对信息/导入旧版配对信息”仍保留用于故障恢复，但日常新增设备应优先
使用用户名和密码登录。配对 JSON 包含可直接访问同步数据的令牌，不应发给其他人。

## 设置项说明

| 选项 | 用途 | 何时需要修改 |
| --- | --- | --- |
| 账号状态 | 显示未登录、已登录用户名或旧版账户状态 | 只读，用于确认当前身份 |
| 用户名 | 同一个同步空间的登录名 | 注册、登录或升级旧账户时填写 |
| 密码 | 向服务器证明账号归属 | 每次登录时填写；客户端不保存 |
| 确认密码 | 防止注册时输错密码 | 仅“注册并登录”和“升级旧版账户”使用 |
| 显示本次输入的密码 | 临时切换密码框可见性 | 确认输入时使用，公共场所建议关闭 |
| 注册邀请码 | 限制陌生人占用私人服务器 | 只在注册时填写；登录不需要 |
| 登录 | 为当前设备创建独立会话令牌 | 已有账号时使用 |
| 注册并登录 | 新建同步账号并登录当前设备 | 只需在第一台设备操作一次 |
| 升级旧版账户 | 给 ID/令牌账户增加用户名和密码 | v1.3.0 老用户使用一次 |
| 在此设备启用本地优先同步 | 控制本机自动上传和下载 | 临时不想联网同步时关闭；不会退出账号 |
| 立即同步 | 跳过等待，立刻推送本机增量并拉取云端增量 | 首次登录、排查延迟或离开设备前使用 |
| 退出登录 | 清除本机会话令牌并尝试在服务器撤销它 | 换账号、出售设备或停止使用同步时使用 |
| 高级与兼容选项 | 展示自托管地址和旧版令牌入口 | 普通用户保持折叠即可 |
| 服务地址 | BanVerse Sync 的 HTTPS 根地址 | 默认官方服务无需修改；自托管时填写自己的地址 |
| 设备名称 | 服务器记录的设备备注 | 建议分别写“家用电脑”“iQOO Neo8”等 |
| 账户 ID | 服务器内部账号标识 | 用户名登录无需输入；旧版连接或恢复时使用 |
| 同步令牌 | 当前设备的直接访问凭据 | 用户名登录会自动保存；不要公开或截图传播 |
| 使用 ID/令牌连接 | 兼容 v1.3.0 的手动登录方式 | 只有旧版凭据或故障恢复时使用 |
| 复制设备配对信息 | 把服务地址、账户 ID 和令牌复制为 JSON | 无法使用密码登录时的备用方式 |
| 导入旧版配对信息 | 从剪贴板读取并校验配对 JSON | 旧版设备迁移；成功后自动清除剪贴板 |
| 状态 | 显示同步进度、上传/接收数量、错误和冲突 | 判断操作是否真正完成 |

## 会同步和不会同步的内容

| 数据 | 结果 |
| --- | --- |
| 角色卡、角色头像 | 同步 |
| 会话、完整消息、消息摘要、角色连续性状态 | 同步 |
| 用户发送图片、角色生成图片 | 同步，并按 SHA-256 校验和去重 |
| 删除角色、会话和消息 | 通过删除墓碑同步到另一端 |
| 文本/图片/TTS API Key | 不同步 |
| TTS 音频缓存、模型列表缓存 | 不同步 |
| 主题、窗口大小等界面偏好 | 不同步 |
| IndexTTS2 本地模型和声音文件 | 不同步 |

首次连接某个账号时，本机已有角色和会话会与云端数据合并，不会自动清空任意一端。
因此推荐先让数据较完整的一端同步完成，再登录第二端。退出账号也不会删除本地聊天，
再次登录同一账号后会继续增量同步。

## 安全与隐私

- 密码使用带随机盐的 scrypt 慢哈希保存，服务器不保存密码原文。
- 登录失败按“来源地址 + 用户名”限流；注册也有来源地址限流。
- 会话令牌默认有效 180 天，可由服务器管理员通过
  `BANVERSE_SYNC_SESSION_DAYS` 调整；退出登录会撤销当前设备会话。
- 注册邀请码由 `BANVERSE_SYNC_REGISTRATION_SECRET` 控制，不应写进源码、README、
  GitHub Actions 日志或客户端安装包。
- 公网服务必须使用 HTTPS。当前同步内容不是端到端加密，服务器管理员仍可读取角色、
  消息和图片；不希望服务器看到的敏感会话不应启用同步。
- BanVerse 当前不提供邮箱找回。忘记密码时不能通过客户端恢复，因此应使用密码管理器
  保存密码；服务管理员应保留数据库与媒体目录的可恢复备份。

## 常见问题

### 提示“邀请码不正确或注册未开放”

注册服务器启用了邀请保护。向服务器管理员获取邀请码；如果账号已注册，应点击“登录”
而不是再次注册。

### 提示“用户名或密码不正确”

确认两端服务地址相同，再重新输入密码。用户名中的英文字母不区分大小写，但密码严格
区分大小写，也不会自动去除首尾字符。

### 提示“登录已失效，请重新登录”

设备会话可能已过期、被退出撤销，或旧版令牌在账户升级后被停用。使用用户名和密码
重新登录即可，本地消息不会因此丢失。

### 登录成功但另一端没有新消息

依次检查：两端账号状态是否显示同一用户名、是否勾选本地优先同步、服务地址是否相同、
状态栏是否有报错。然后在有完整数据的一端点击“立即同步”，完成后再在另一端点击一次。

### 两端都有不同的本地历史

首次登录会合并两边的不同实体。若同一个实体被离线同时修改，先到服务器的一版成为
当前版本，另一版保存在本机 `sync_conflicts` 表供后续排查，不会静默覆盖。

### 退出登录会删除消息吗

不会。退出只清除当前设备的同步凭据和游标，本地角色、会话与图片全部保留，也不会
自动删除服务器上的同步副本。
