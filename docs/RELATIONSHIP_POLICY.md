# 关系边界与主动消息策略

BanVerse 将关系策略设计成用户可理解、可修改的规则，而不是展示“亲密度 87”一类
隐藏分数。隐藏连续性状态仍可帮助角色保持情绪因果，但模型生成的关系变化会经过本地
限幅：普通寒暄不改变关系阶段，明确冲突、修复、承诺或边界事件也只能按慢热、自然或
较快策略小幅变化。

## 全局默认与角色覆盖

设置页提供关系发展速度、偏好称呼、欢迎话题、禁止话题、主动联系频率、每日上限和
静默时段。角色页的“关系与联系”可以继承全局值，也可以为单个角色完整覆盖；静音和
临时暂停始终可单独设置。暂停支持一天或指定本地时间，界面同时展示最近一次允许或
拦截主动消息的原因。

这些边界会加入角色正文、首次开场和主动消息的系统上下文，并明确高于角色卡、世界书、
历史召回与隐藏 Director 节拍。角色不得用愧疚、威胁离开、排他要求、催回复或诱导依赖
来表达亲密。

## 调用模型前的确定性门禁

随机计时到期不代表一定调用 API。应用按以下顺序在本地检查：

1. 全局开关、角色静音、频率和每日上限；
2. 暂停截止时间与跨午夜静默时段；
3. 用户最近是否明确要求安静、停止联系或不要催促；
4. 最近 24 小时是否出现需谨慎处理的敏感事件；
5. 最近互动是否不足 30 分钟，以及该频率对应的主动消息冷却；
6. 当前本地日期下已经完成的主动消息数量。

任一条件不满足都不会创建轮次，也不会调用文本模型。通过后，模型可参考设备本地时间、
工作日/周末、角色自己的生活、已确认用户信息、共同经历和未完话题，但不得臆造天气、
地理位置、用户作息或用户正在做的事。近期主动消息会作为去重上下文；生成结果仍与最近
五条主动消息做本地片段相似度检查，过度重复会在投递前删除。

## 双端幂等

每个会话按“本地日期 + 当日消息序号”生成确定性 SHA-256 事件槽。PC 与手机在相同状态下
会得到同一个槽 ID，并在生成前向同步服务竞争 `proactive` 租约。主动消息租约最长可覆盖
到下一个本地日期之后的安全窗口，避免旧版 180 秒租约过期后另一台设备重复发送；普通
租约仍保持 10 分钟上限。最终消息继续通过已有 turn 同步和事件 ID 去重。

关系与联系策略目前是设备本地偏好，不上传 API Key，也不上传额外遥测。双端使用时应在
两台设备分别确认静默和角色覆盖设置；服务端租约负责防止同一事件槽重复生成。

## 确定性测试

离线测试覆盖跨午夜静默、夏令时前后 UTC 偏移、本地日期切换、休眠后重新判定、暂停、
禁用、用户拒绝、敏感场景、冷却、每日上限、重复文本、关系缓变和双设备租约竞争。
第三方模型输出与网络可用性不作为 CI 的确定性硬门禁。
