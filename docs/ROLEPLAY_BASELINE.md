# BanVerse 角色扮演离线基线

本基线对应 `v1.4.0` 之后、阶段五诊断实现时的确定性结构检查。它不调用模型、不访问网络，
也不使用真实用户聊天；用途是发现角色卡、提示结构和样例集的明显回退，不代替人工 A/B 评价。

## 当前覆盖

- 6 个内置角色，5 位女性、1 位男性；每个角色至少关联一个回放场景。
- 8 个场景：日常、冲突、脆弱、回忆、主动消息、剧情推进、图片事件和 TTS 分段。
- 10 条供应商/模型冒烟矩阵，覆盖文本、图片生成、视觉理解和 TTS。
- 在线冒烟需要真实凭据时必须手动运行；缺少凭据记为 `skipped`，不得伪造通过。

供应商矩阵的机器可读源位于
`tests/fixtures/provider_model_matrix.json`，回放样例位于
`tests/fixtures/roleplay_regression_cases.json`。

## 当前结构指标

| 指标 | 当前值 | 门禁 |
| --- | ---: | ---: |
| 角色卡区分度 | 0.9575 | ≥ 0.65 |
| 固定开头重复率 | 0.0000 | = 0 |
| 带问号回复比例 | 0.1250 | ≤ 0.50 |
| 每轮强制提问 | false | false |
| 无原因情绪跳变 | 0 | = 0 |
| 用户事实冲突 | 0 | = 0 |
| 隐藏格式泄漏 | 0 | = 0 |

## Director 实验基线

以默认阈值 `6/10` 模拟开启关键轮次 Director 时，8 个场景中仅冲突、脆弱和剧情推进触发：

| 指标 | 当前值 |
| --- | ---: |
| 触发率 | 37.5%（3/8） |
| 理论平均角色模型调用数 | 1.375/轮 |
| 每轮最大额外调用 | 1 |
| Director 超时预算 | 8 秒 |
| 默认开关 | 关闭 |

离线结构检查无法证明双阶段生成优于单阶段，因此实验开关保持关闭。开启后应使用相同供应商、
模型、角色和输入做人工 A/B，并重点比较首段可见时间、角色决策质量和额外费用。

## 重新生成

```powershell
.\.venv\Scripts\python.exe tools\generate_roleplay_baseline.py
.\.venv\Scripts\python.exe tools\generate_roleplay_baseline.py --output build\roleplay-baseline.json
```

脚本输出包含 `network_used: false` 和 `contains_user_data: false`。修改角色卡、提示、回放样例或
质量指标后，应同时提交新结果、阈值变化原因和人工检查结论；不能只降低阈值来消除失败。
